
Regras adicionais para evitar falsos positivos:

1. JSON.stringify() apenas serializa valores para texto JSON.
   Não reportes execução de código ou injeção de JavaScript
   apenas por existir uma função json() que utiliza JSON.stringify().

2. Uma aplicação pode ter rotas públicas e rotas privadas.
   Não exijas autenticação global na função createServer().
   Verifica a autenticação individual das rotas que precisam de proteção.

3. Antes de reportar ausência de autenticação, procura no
   código verificações como req.headers.authorization,
   comparações com Bearer e respostas HTTP 401.

4. Só reportes uma vulnerabilidade quando conseguires
   identificar uma operação concreta que a torna possível.
   Não apresentes hipóteses genéricas como vulnerabilidades
   comprovadas.

5. Não repitas problemas e não inventes vulnerabilidades
   apenas para preencher a lista.
